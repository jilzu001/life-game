## 구현 내용

- 세계관별 공통 갈등과 존재의 입장에 맞는 전용 사건을 작성했다. 실제 배포 JSON에 모든 제목·서술·선택·결과·효과·조건을 저장하며 런타임 이야기를 생성하지 않는다.
- 출생별 초기 능력치와 위치·특징·결함 효과를 다르게 설정했다. 특징·결함은 전용 선택 조건에도 연결했다.
- 숨겨진 운명은 공개 사건과 운명별 조건부 선택에 연결했다. 앞서 선택한 내용에 따라 후속 전용 선택이 열리는 경로를 추가했다.
- 약속·개혁·위험·역할 전환 플래그와 능력치 조건을 조합해 세계별 기본·전설·파멸·역전·질서 변화의 엔딩 5종을 배치했다.
- 기존 마검→인간 모험가에 더해 슬라임→드래곤, 좀비→인간 생존자, 자판기→기업 서버 AI, 던전 보스→F급 헌터의 변신을 추가했다.
- 세계 6·존재 30·엔딩 30개의 대표 SVG, 재사용 사건 장면 24개, 대체 이미지 1개를 연결했다. 외부 참조·스크립트 없이 단순 벡터로 제작했다.
- UI는 세계별 강조색과 시작 소개·실제 콘텐츠 수량 안내만 수정했다.
- **엔진·스키마·의존성을 변경하지 않았다.** 새 규칙은 기존 선언형 데이터로 표현했다.

## 버전과 저장

앱 버전 `0.4.0`, 콘텐츠 버전 `0.4.0-mvp`, 스키마 버전 1이다.

추첨 풀과 출생 문장이 바뀌어 기존 `0.2.0-phase2` 저장을 그대로 재현할 수 없다. 기존 엔진의 비호환 안내로 새 인생 시작을 요청한다. 이전 저장은 자동 삭제하지 않고 새 인생 확정 시 교체한다. 현재 버전 내 저장·복원과 다음 선택의 결정성은 30종 모두 검사했다.

## 검증 결과

- `npm run validate:content -- --report`: 스키마·ID·참조·출생 조합·이미지·MVP 수량·도달성 검사 통과.
- 세계별 시드 0~4095 × 첫 선택·마지막 선택·순환·고정 난수의 네 전략 × 6세계 = **98,304회 모두 12개 사건과 엔딩까지 완주**.
- 각 세계의 모든 출생 유형·일반 사건·선택지·명시적 직접/조건 분기·엔딩을 관측했다. 정상 경로의 안전 사건 사용은 **0회**다.
- `npm run test`: **7개 파일, 129개 테스트 통과**. 이전 95개를 유지하고 실제 MVP 통합 검사 34개를 추가했다.
- 30개 출생 유형 각각을 전체 6세계 추첨에서 찾아 출생 확정과 매 선택, 총 390개 상태에서 저장·복원했다. 복원 전후 다음 선택 결과도 일치했다.
- 다섯 변신 경로를 실제 선택으로 실행하여 출생·이력 유지와 저장 복원을 검사했다.
- 실제 Phase 2 저장을 새 콘텐츠로 읽을 때 비호환 안내가 나오고, 새 인생 확정 전에는 원본이 유지되는 것을 검사했다.
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 사용 SVG **91개 모두 XML 구문 확인**. 경로·viewBox·외부 참조/스크립트 금지 검사를 통과했다.
- 유한 시드 검사는 모든 가능한 선택 조합에 대한 수학적 증명이 아니다. 재현 가능한 시드와 분기 기록으로 범위를 명시했다.

## 검증 중 해결한 문제

1. 새 좀비 기본 엔딩의 ID가 인간 생존자 ID와 충돌했다. 새 세계의 엔딩 ID에 `ending` 구분자를 넣어 수정했다.
2. 기존 판타지 성장 단계는 직접 분기가 차지하므로 새 성장 전용 사건에 도달하지 못했다. 기존 사건·엔진을 바꾸지 않고 신규 사건의 단계를 위기로 조정했다.
3. 현실 인간의 동일한 태그 두 개를 중복 검증기가 거부했다. 중복 항목을 제거했다.
4. 범용·조건부 선택 추가 후 1,024시드 표본에서 희귀 후속 선택 2개가 미관측됐다. 조건과 검사를 완화하지 않고 표본을 4,096시드로 확장해 실제 도달을 확인했다.
