## 검증 결과

- `npm run validate:content`: 통과. 스키마·참조·이미지 검사와 256회 완주 시뮬레이션 포함.
- `npm run test`: **5개 파일, 85개 테스트 통과**. 기존 51개와 신규 34개.
- `npm run build`: TypeScript 검사·Vite 프로덕션 빌드 통과.
- 시드 0~63 × 네 선택 전략 = **256회 모두 사건 12개와 엔딩까지 도달**.
- 등록된 두 출생 유형, 일반 사건 19개, 모든 선택지, 명시적 직접·조건 분기, 엔딩 5개를 모두 관측했다.
- 정상 샘플 경로의 안전 사건 사용은 0회. 일반 사건을 모두 제거한 별도 테스트에서 안전 사건만으로 12회 후 엔딩 도달 확인.
- 저장 테스트는 시작 및 12개 선택 시점마다 복원하고 다음 상태가 원래 진행과 동일한지 비교했다. 난수·현재 사건·단계·변신·이력·엔딩을 포함한다.
- 잘못된 저장 형식, 콘텐츠/저장 버전 불일치, 능력치·난수·존재·단계·선택 이력·공개 상태 불일치, localStorage 접근·쓰기 실패, 중복 클릭을 확인했다.
- 실제 브라우저: 시드 42의 마검으로 시작 → 직접 분기 → 왕실 출생 조건 분기 → 저주 해결 → 운명 공개 → 인간 변신 → **‘칼날이 걷는 아침’ 엔딩**.
- 브라우저에서 완료 횟수 2·8·12의 세 시점에 새로고침하여 성장 단계·변신 상태·엔딩의 복원을 확인했다. 이미지와 과거 기록 유지, 콘솔 오류·경고 없음.
- 엔딩 복원 화면은 `docs/qa/phase2-browser.jpg`에 보관했다.

최초 신규 테스트 실행에서 85개 테스트는 통과했으나 테스트 도우미의 좁은 추론 타입 때문에 빌드가 실패했다. 해당 도우미를 `Content`로 명시하고 수정 후 모든 검사를 통과했다. 테스트를 삭제하거나 검사 조건을 완화하지 않았다.

## 규칙과 다음 작업 주의사항

- 콘텐츠 버전은 `0.2.0-phase2`, 스키마 버전은 1이다. 선택 필드 `chaosWeight`, `isFallback`, `revealsFate`만 추가했다.
- 조건 평가·분기 우선순위·방문 제한·변신·저장 규칙은 `ENGINE.md`, 데이터 작성은 `CONTENT_FORMAT.md`를 따른다.
- 콘텐츠를 바꿀 때 저장 재현에 영향을 주면 콘텐츠 버전을 갱신한다. 호환되지 않는 저장은 안내 후 새 인생 확정 시 교체한다.
- 현재 자동 도달성 검사는 유한한 시드와 전략 집합의 검사다. 임의의 모든 조건 조합에 대한 증명은 아니다. 미도달 항목은 오류로 보고하고 조건·우선순위·재현 시드를 조사한다.
- 같은 세계관 내 변신만 지원한다. 현재 존재를 바꾸면서 출생 조건과 과거 선택을 보존한다.
- Phase 1 테스트는 보존한 원본 샘플을 사용하고, 실제 최신 콘텐츠는 별도 통합 테스트와 시뮬레이션에서 검사한다.
- 정식 모바일 UI, iframe 높이 동기화, 티스토리 저장 제한 환경, GitHub Pages 실배포, 전체 MVP 콘텐츠는 미구현·미검증이다.
- **다음 단계는 Phase 3 기본 UI이며, 명시적인 후속 지시 후 진행한다.**
