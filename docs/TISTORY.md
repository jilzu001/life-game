# 티스토리 복붙용 글

추천 제목: **무한생 — 이번 생에는 무엇으로 태어날까? 선택형 인생 게임**

`public/blog.html`이 완성된 본문 코드다. 소개·사용법·게임 iframe·새 창 링크·세계관·선택의 영향·저장 안내가 포함되어 있다.

1. 티스토리에서 새 글을 열고 제목을 입력한다.
2. 편집기 모드를 **HTML**로 바꾼다.
3. `public/blog.html` 파일의 전체 내용을 그대로 붙여 넣는다. 별도 HTML 문서의 head나 body를 추가할 필요가 없다.
4. 미리보기에서 게임과 새 창 링크가 열리는지 확인하고 게시한다.

[소개 글 미리보기](https://jilzu001.github.io/life-game/blog.html) · [복사할 원본 코드](https://github.com/jilzu001/life-game/blob/main/public/blog.html)

기본형은 외부 스크립트 없이 iframe 내부를 스크롤하는 방식이다. 높이는 980px이며, 원하는 경우 iframe의 `height="980"`과 `height:980px` 두 곳을 함께 변경한다. 자동 높이 조정이 필요한 경우 `EMBED.md`의 선택적 코드를 참고한다.

GitHub의 공개 소개 페이지와 iframe을 검증한 뒤 결과를 상태 문서에 기록한다. 실제 티스토리 계정에서 글을 게시하거나 해당 블로그 스킨·저장 정책을 확인한 것은 아니다.
