## Phase 5 변경

- `.github/workflows/pages.yml`: Linux에서 콘텐츠 → 테스트 → 빌드 → 배포 파일 검사 후 dist만 게시한다. PR은 검증만 실행한다.
- `scripts/validate-dist.mjs`: public 원본과 빌드 복사본 일치, 콘텐츠·이미지 참조, 실제 파일명 대소문자, HTML·청크·CSS 자원, 루트 및 프로젝트 경로를 검사한다.
- `tests/deployment.test.js`: 정상 배포, 대소문자 오류, 청크 누락, 오래된 콘텐츠 빌드 차단을 추가했다.
- `.gitattributes`: Windows와 Linux의 소스 줄바꿈을 LF로 통일하고 바이너리 이미지를 보호한다.
- `docs/DEPLOYMENT.md`: 배포·갱신·게시 후 확인·복구 절차. `docs/EMBED.md`에는 실제 GitHub 주소를 반영했다.
- 버전·스크립트·잠금 파일 및 README·CHANGELOG·HANDOFF를 갱신했다. 의존성 추가는 없다.
