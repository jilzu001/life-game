# 기본 UI

Phase 3의 시작·운명 생성·사건·엔딩 화면이다. `src/main.ts`가 기존 `GameSession`을 호출하고 상태에 맞는 화면을 렌더링한다. 화면은 전달받은 상태를 표시하며 게임 규칙을 직접 변경하지 않는다.

- `start.ts`: 새 인생 생성, 저장된 인생 이어하기·지난 생 보기
- `birth.ts`: 공개 출생 조건, 능력치, 다시 뽑기·시작
- `game.ts`: 사건과 선택, 진행률, 현재 존재·능력치, 접는 과거 기록
- `ending.ts`: 엔딩, 최종 상태, 출생 조건, 전체 선택 기록
- `shared.ts`: 안전한 텍스트 DOM, 이미지 대체, 아이콘, 능력치, 출생 조건·기록
- `embed.ts`: 부모 프레임에 실제 콘텐츠 높이 전달

숨겨진 운명은 공개 상태가 되기 전까지 렌더링하지 않는다. 버튼은 네이티브 button을 사용하고 화면 전환 시 제목으로 초점을 옮긴다. iframe에서는 부모 스크롤도 제목을 따라갈 수 있도록 브라우저의 기본 초점 스크롤을 허용한다. 스타일은 `src/style.css`에 있으며 800px·560px 이하에서 세로 배치로 전환한다.

개발용 시드·JSON 화면은 `diagnostics.html`, `src/diagnostics.ts`, `src/diagnostics.css`에 보존했다. 정식 UI와 같은 엔진·저장 키를 사용하므로 진단 화면에서 시작하거나 선택하면 같은 브라우저의 저장 인생도 갱신된다.
